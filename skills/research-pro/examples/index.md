# Worked examples

Before/after pairs with the reasoning shown. Read the one for the problem in front
of you; do not read them all.

| File | Shows |
|---|---|
| `01-humanizer-before-after.md` | Machine-register prose → human prose, in three measured stages. Every number is real `prose_metrics.py` output, including a stage that still fails. |
| `02-gap-paragraph.md` | The Introduction's hinge paragraph: patch framing vs limitation-without-reason vs challenge framing, clause by clause. |
| `03-limitations.md` | Ritual limitations → specific ones, and the line you must not cross (a missing experiment relocated to page 8). |
| `04-ledger-catches-a-claim.md` | Gate 1 in action: how the claim/evidence ledger caught an unsupported abstract claim, and the two honest ways to close it. |

The examples use one running paper — a sparse-expert-routing method — so the moves
compose. None of its numbers are real; they are placeholders for the shape of an
argument, and no example should be cited as a result.
