# Worked examples

Before/after pairs with the reasoning shown. Read the one for the problem in front
of you; do not read them all.

| File | Shows |
|---|---|
| `01-humanizer-before-after.md` | Machine-register prose → human prose, in three measured stages, plus the over-corrected register for contrast. Every number is real `prose_metrics.py` output, including a stage that still fails and a `--compare` row that gets worse. |
| `02-gap-paragraph.md` | The Introduction's hinge paragraph: patch framing vs limitation-without-reason vs challenge framing, clause by clause. |
| `03-limitations.md` | Ritual limitations → specific ones, and the line you must not cross (a missing experiment relocated to page 8). |
| `04-ledger-catches-a-claim.md` | Gate 1 in action: how the claim/evidence ledger caught an unsupported abstract claim, and the two honest ways to close it. |
| `05-lit-map-to-gap.md` | `lit_scan.py` output → reading depth → the filled map → reading down the `Fails when` column → the gap paragraph and the Related Work groupings it produces. |
| `06-citation-that-did-not-say-that.md` | Gate 2, Layer 3: the real `verify_citations.py` worklist on a fixture with a citation stack, a retracted source, an unfinished ledger row, and the claim-drift case no script catches. Each row closed honestly. |

The examples use one running paper, a sparse-expert-routing method, so the moves
compose. None of its numbers are real; they are placeholders for the shape of an
argument, and no example should be cited as a result. The literature in example 05 is
fictional end to end, including every author, title, DOI and citation count.
