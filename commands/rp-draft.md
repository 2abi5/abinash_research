Invoke `research-pro`. Read `references/00-operating-rules.md` (if not already read
this session) and the ONE section file for: $ARGUMENTS

- Abstract / title / intro → `references/09-abstract-title-intro.md`
- Related work → `references/04-related-work.md`
- Method → `references/05-method.md`
- Experiments → `references/06-experiments.md` (+ `references/07-results-and-stats.md`)
- Discussion / limitations → `references/08-discussion.md`
- Conclusion → `references/10-conclusion.md`

Do not read the others.

Work paragraph by paragraph, not section-at-once. After the section is drafted,
reverse-outline it immediately (`references/12-prose-quality.md`) — do not defer
this to the end of the paper.

Return: the actual LaTeX ready to paste · claim/evidence rows for anything new you
asserted · what you changed and why in a few lines · open items as
`[NEEDS SOURCE]` / `[TBD]` / `[NEEDS EXPERIMENT]` / `[AUTHOR DECISION]`.

Never invent a number, a baseline result, or a citation.
